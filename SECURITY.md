# Security

## Reporting a vulnerability

Please report security issues privately to **info@parallexlabs.ca**. Do not open public issues for sensitive reports.

## Scope

This is a static client-side web application. User text is processed in the browser only. Optional model downloads come from Hugging Face CDN when the user explicitly requests them.

## Privacy

No analytics, cookies, or server-side storage of user content are used by this lab.
