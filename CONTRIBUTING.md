# Contributing

Thank you for your interest in the Translation Check Lab.

## How to contribute

1. Fork the repository and create a branch.
2. Run `npm ci`, `npm test`, `npm run lint`, and `npm run check:site` before submitting changes.
3. Keep practice content synthetic and labelled as illustrative.
4. Cite public sources for any factual claims added to user-facing text.

## Code of conduct

Follow the same professional standards as the [Humanitarian AI Training Kit](https://parallexlabs.github.io/humanitarian-ai-training-kit/).
